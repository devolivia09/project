## Portfolio Project <br>
<br>

Axis : 미니멀리즘 공간과 인터랙션의 연결<br>
장식을 배제한 미니멀리즘 공간 안에서, 사용자의 스크롤은 화면의 요소들을 하나로 연결하는 핵심 축(Axis)이 됩니다.

<br>
- 프로젝트 개요<br>
본 프로젝트는 웹 퍼블리셔로서의 기술적 역량과 디자인 철학을 담은 개인 포트폴리오입니다.<br>
불필요한 장식을 배제하고, 사용자의 스크롤 흐름에 따라 반응하는 인터랙션을 구현하는 것에 집중했습니다.<br>
<br>
- 기술과 사용자 사이의 연결<br>
    전자기기 화면 속 수많은 정보와 요소들의 홍수 속에서 사용자들은 무엇이 중요한지 알 수 없어 모두 놓치기 쉽습니다.<br>
그래서 점, 선, 면, 텍스트를 화면에 배치하였습니다.<br>
사용자들이 집중해야 하는 것을 최소화 함으로써, 역으로 중요한 것에만 집중하도록 하였습니다.<br>
<br>
- 정적이면서 동적으로<br>
바우하우스의 실용적 기능주의와 수묵화의 절제된 여백에서 화면의 영감을 얻었습니다.<br>
또한 사용자의 스크롤에 따라 요소들이 유기적으로 반응하도록 설계하여 지루함에 빠지지 않도록 했습니다.<br>
결과적으로 정적인 화면에서 동적인 연결을 만듦으로써 몰입감과 집중도를 잃지 않도록 했습니다.<br>
