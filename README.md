# Portfolio Project

> 미니멀리즘과 인터랙션의 연결, 사용자와 요소들의 연결

## 📌 Project Overview
본 프로젝트는 웹 퍼블리셔로서의 기술적 역량과 디자인 철학을 담은 개인 포트폴리오입니다. 
불필요한 장식을 배제하고, 사용자의 스크롤 흐름에 따라 반응하는 정교한 인터랙션을 구현하는 데 집중했습니다.

## 📌 기술과 사용자 사이의 연결
단순히 정보와 요소를 화면에 나열하면, 사용자들은 무엇에 집중해야 하는지 몰라 모두 놓치기 쉽습니다.
그래서 미니멀한 요소들인 점, 선, 면, 최소한의 텍스트를 화면에 배치하였습니다.
사용자들이 집중해야 하는 것을 최소화 함으로써, 역으로 정말 중요한 것에만 집중하도록 하는 화면 구성이 목표였습니다.

## 📌 간결함과 동적 연결
바우하우스(Bauhaus)의 실용적 기능주의와 수묵화의 절제된 여백에서 영감을 얻었습니다. 
그러면서도 사용자의 스크롤에 따라 요소들이 유기적으로 반응하도록 설계하였습니다.
정적인 화면에서도 몰입감과 집중도를 잃지 않게 하는 동적인 '연결'을 지향했습니다.

## 🛠 Tech Stack
- **Script:** Vanilla JavaScript (ES6+)
- **Style:** CSS3 (BEM, Flexbox)
- **Library:** GSAP (ScrollTrigger)
- **Tool:** Figma, Git
